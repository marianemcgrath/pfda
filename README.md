## ⚡ Quick Start

Here is how to launch this project: 🚀

1. **Grab the code:**
git clone https://github.com/marianemcgrath/pfda

2. ** Select "assignments" Folder**

3. **Install your tools:**
    pip install pandas matplotlib numpy requests
